# 📚 Paradigma de Programação POO I

## 📌 Descrição

Este repositório contém aulas e exercícios desenvolvidos durante a disciplina de Paradigma de Programação Orientada a Objetos (POO). O objetivo é consolidar, por meio da prática, os principais conceitos da programação orientada a objetos.

## 📁 Estrutura do Repositório

* 📂 aulas → exemplos e conteúdos apresentados durante as aulas
* 📂 exercicios → atividades práticas propostas ao longo da disciplina

## 🧠 Conteúdos Abordados

* Estudo e aplicação de classes (atributos e métodos)
* Instanciação de objetos
* Encapsulamento de variáveis e métodos
* Agregação e composição
* Generalização e especialização (herança)
* Polimorfismo
* Classes abstratas
* Interfaces

## 🚀 Tecnologias Utilizadas

* Java
* IntelliJ IDEA

## 📌 Notas

Repositório voltado para fins acadêmicos.
